# Read Me -- Worthy
Hello! This game is just a short text-based decision making game that I made, not only for fun but to also remember how to code using Java. It is currently not finished, as there is an ending that is not complete yet but it should still be playable to some extent. I may or may not add more elements to the game when I finish the programming the endings. 

## Overall Theme:
The game is supposed to be kind of uncanny (?) or provide an uneasy feel. The whole premise of the game is a metaphor for guilt or taking accountablity for what you've done, which depends on the ending. It's a random concept that I came up with on a random day. I do think that there should be more horror games that tap into human emotions -- like guilt for example -- and so I am experimenting with it.
